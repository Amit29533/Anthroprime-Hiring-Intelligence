# Import and workspace navigation

Candidate import starts with source sections: LinkedIn, CV documents,
spreadsheet, application email and, in hosted workspaces, saved imports.
Only one source is expanded at a time. Spreadsheet mapping and CV review
keep their existing validation and persistence paths. Saved reviews link
directly to the saved-import section.

LinkedIn follows three steps: open the helper, import its result, then review
and save. An accepted result opens the review step and moves keyboard focus
to its heading. Refresh/forget controls live under Manage login and setup;
text import and configured providers live under Other import methods.
Extraction notes are expandable. Identity, contact, evidence, duplicate and
confirmation checks still apply before saving.

Overview queues and advanced tools use the same disclosure component.
Specialist tools are grouped under Reports, integrations and administration.
Closed, unvisited sections do not mount or fetch data. Visited sections remain mounted
while hidden, preserving drafts and ongoing work. Workspace or role changes
remount scoped tools. Role restrictions and recovery links remain supported.

Disclosure triggers are native keyboard-operable buttons with expanded state
and named content regions. Icons supplement text. Shared theme tokens support
light/dark modes, narrow layouts wrap labels and actions, and reduced-motion
preferences disable the reveal animation. Opening a section keeps its trigger
visible when content height changes.
